À PROPOS DES PROBABILITÉS

Comment fonctionne le tirage

Le mode démographique pondère 199 pays et territoires émetteurs de passeports selon leur population. Les lieux plus peuplés sont plus souvent tirés.

Ce sont des probabilités de jeu, pas des probabilités réelles de naissance ou de nationalité. Le mode égal donne la même chance à chaque lieu.

Les lieux exclus sont retirés et les poids restants sont normalisés. Les liens partagés affichent ton passeport ; les visiteurs lancent leur propre jeu depuis l’accueil.
