# rebirth_country_es

Edición en español de rebirth_country.

https://nanalab.kr/rebirth_country_es/

Conserva los pesos originales, los intentos, el menú nativo para compartir y la descarga JPG. Los enlaces abren el inicio; la vista OG muestra el resultado y la probabilidad traducidos. Se conservan las licencias y los créditos. No usa SDK ni clave de Kakao.

```text
npm ci
npm run build
npm test
```
